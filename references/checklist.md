# 生成后自检

页面写完后、交给用户前，对照这份清单检查一轮。能截图或在浏览器里预览就看着实际效果查，桌面宽度和手机宽度（375px）一起看；不能预览就逐条读代码查。

**只查一轮，发现的问题一次性全部改完，最多再复查一轮，然后交付。** 不要反复打磨。

用模板 `assets/workbench.html` 生成时，“布局”到“浏览器自带的部分”这几节模板已经做好，**重点查“用户的需求”和“配置”两节**；只有当你按 `design.md` 改动了模板以外的视觉时，才需要把后面几节也查一遍。

## 配置

- [ ] 配置是合法 JSON（能运行代码就用解析器验证）：双引号、没有多余逗号、没有注释。
- [ ] 只改了 `<script id="workbench-config">` 里的内容，模板其他部分原样未动。
- [ ] `id` 只含英文字母、数字、连字符；修改工作台时与原来完全一致。
- [ ] `theme`、`layout`、每个模块的 `type` 和 `area` 都是 `modules.md` 里列出的合法值。
- [ ] 每个 `project`、`member` 引用都在 `projects`、`members` 中定义过。
- [ ] 日期是 `YYYY-MM-DD`，并且按今天的实际日期正确推算；`weekday` 在 1 到 7 之间。
- [ ] 没有编造的待办、金额、网址和日期；不确定的网址没有写进去。
- [ ] 模块 4 到 7 个，主模块排在最前；同一种模块出现两次时各有不同的 `id`。
- [ ] AI 指令贴合用户的工作，需要填写的地方用方括号标明。

## 用户的需求

- [ ] 问答中用户提到的每个需求都有对应的模块，并且在首屏或一次滚动内能找到。
- [ ] 用户最常用的模块是页面上最显眼、面积最大的那个。
- [ ] 内容用的是用户说过的真实信息，没有“任务一”“示例文本”之类的占位。
- [ ] 文案是用户的说法，按钮写的是具体动作。

## 布局

- [ ] 模块大小有主次，没有整页等大格子。
- [ ] 没有卡片套卡片；每个模块边框和阴影只用了一种。
- [ ] 375px 宽度下是单列，左右 16px，没有横向滚动，没有文字溢出或被截断。
- [ ] 间距都用 `--space-*`，同组紧、组间松。

## 字体和颜色

- [ ] 只用了主题字体栈，没有引入其他字体；网络字体只用在标题上，带 `display=swap`。
- [ ] 正文 15–16px（手机不小于 16px），中文行高约 1.7，长文每行不超过约 40 个汉字。
- [ ] 数字、金额、时间用了 `tabular-nums`。
- [ ] 组件里没有裸色值，全部是主题变量；切换浅色和深色后所有地方都正常。
- [ ] 正文和占位文字对背景对比度至少 4.5:1；在彩色底上的文字也达标。
- [ ] 状态（完成、逾期、出错）不只靠颜色区分，同时有图标或文字。
- [ ] 主题的标志性细节出现了，并且只出现在一个地方。

## 图标

- [ ] 只用了 `assets/icons.svg` 里的图标，尺寸和线宽统一。
- [ ] 没有 emoji 或 Unicode 符号充当图标。
- [ ] 只有图标的按钮都有 `aria-label` 和 `title`。

## 交互和状态

- [ ] 每个可点的元素都有悬停、按下和键盘聚焦样式，聚焦框清晰可见。
- [ ] 用 Tab 键能按视觉顺序走完所有操作，没有只能靠鼠标悬停才出现的唯一操作。
- [ ] 每个模块都写了空状态：说明放什么，给一个开始的按钮。
- [ ] 删除等不可撤销的操作有确认，或者提供“撤销”。
- [ ] 保存、加载、出错都有反馈；出错时说清楚原因和办法。
- [ ] 拖动排序之外，还有按钮或菜单可以完成同样的事。
- [ ] 动效最多一个编排过的时刻，`prefers-reduced-motion` 下直接显示最终状态。

## 数据

- [ ] 用户输入的内容会保存，刷新页面后还在。
- [ ] 读写本地存储都包在 `try/catch` 里；存储不可用时页面照常显示，并提示“这次的修改不会被保存”。
- [ ] 提供“导出数据”（下载 JSON）和“导入数据”，换电脑或换浏览器时不会丢。
- [ ] AI 生成的内容旁边标明“由 AI 生成”。

## 浏览器自带的部分

- [ ] 文字选中色、输入光标、复选框、滚动条、链接下划线都跟随主题（引入 `themes.css` 的基础层即可，检查没有被覆盖掉）。
- [ ] 页面有 `<meta name="viewport" content="width=device-width, initial-scale=1">` 和 `<html lang="zh-CN">`。

## 顺手看一眼

以下任意一项出现了，又不是用户要求的，就改掉：紫蓝渐变、渐变文字、装饰性毛玻璃、彩色粗竖边、模块上方的小字标签、01/02 编号、不承载真实数据的进度环或迷你折线图、背景条纹或网格、近黑色冒充黑色。
