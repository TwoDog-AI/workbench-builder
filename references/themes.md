# 主题库

所有数值在 `assets/themes.css`，这里讲每个主题适合谁、长什么样、怎么选。`assets/theme-preview.html` 可以直接打开，看同一个工作台在六个主题下的样子，可以拿给用户挑。

## 1. 怎么选

1. 问答结束后，根据用户的职业和使用场景，从下表挑 **两个** 最合适的主题推荐给用户，用一句话说明各自的感觉，让用户选。不要把六个全部摆出来。
2. 用户说不清时，默认选推荐里的第一个，告诉他随时可以换。
3. 浅色还是深色：先跟随系统；用户说过常在晚上用、眼睛累，就默认深色。
4. 用户自己提出了明确的风格（“我想要粉色的”“像 Notion 那样”），以用户为准：选最接近的主题做底，在它的变量上调整，不要硬塞主题原样。

| 主题 | `data-theme` | 适合谁 | 一句话感觉 |
|---|---|---|---|
| 青瓷 | `celadon` | 写作者、老师、研究人员、学生 | 安静、像一张好的书桌，字是主角 |
| 导视 | `wayfinding` | 项目经理、运营、同时跟多个客户的自由职业者 | 像地铁导视，多条线一眼分清 |
| 对账 | `ledger` | 财务、销售、电商店主、记账的人 | 紧凑、数字对得齐，红字就是亏 |
| 夜读 | `nightdesk` | 程序员、设计师、常熬夜工作的人 | 暗下来的房间里亮着一盏灯 |
| 庭院 | `courtyard` | 宝妈宝爸、管家庭事务、记录生活 | 温和、圆润，每个家人有自己的颜色 |
| 画室 | `studio` | 设计师、内容创作者、自媒体 | 大量留白，只在一处大胆 |

## 2. 每个主题的细节

每个主题只贡献四样东西：字体、配色、密度、一个标志性细节。布局和控件仍按 `design.md` 用标准做法。**标志性细节每个页面只出现在一个地方。**

### 青瓷 celadon

- **字体**：标题宋体，正文黑体。
- **配色**：灰绿色的底，墨绿色主色，朱砂红只用在一处。
- **密度**：偏松（1.1），行距舒展。
- **标志细节**：页面顶部今天的日期用大号宋体（`--text-2xl` 或 `--text-3xl`），旁边一枚小小的朱砂方印，里面一个“今”字（`--accent` 底、`--on-accent` 字，圆角 `--radius-sm`）。朱砂色在整页只出现这一次。
- **适合的骨架**：单栏，或侧栏 + 主区。

### 导视 wayfinding

- **字体**：全黑体，标题字重 800。
- **配色**：干净的浅灰底，导视蓝主色，导视黄做高亮（黄底黑字，不做文字色）。另有六种“线路色” `--line-1` 到 `--line-6`。
- **密度**：标准（1）。
- **标志细节**：每个项目分配一种线路色。项目名前放一枚线路标：圆角方块，线路色底，里面是项目的一个字或一个字母（浅色模式白字，深色模式用 `--bg` 色的字）。属于该项目的待办前加一个同色小圆点。不要用彩色粗竖边表示归属。
- **适合的骨架**：侧栏 + 主区（侧栏列出各条线路），或不均分网格。

### 对账 ledger

- **字体**：黑体；数字用 `--font-num`（等宽）。
- **配色**：几乎无彩，墨绿色是唯一主色。`--negative` 专门给负数用。
- **密度**：紧凑（0.85），一屏多放信息。圆角很小，没有阴影，用细线分隔。
- **标志细节**：所有金额和数量右对齐、带千分位、用等宽数字；负数用红字（`--negative`），同时保留负号，不只靠颜色。汇总行加一条上边线。
- **适合的骨架**：不均分网格，主区放表格或流水。

### 夜读 nightdesk

- **字体**：黑体；计时器数字用等宽。
- **配色**：深色模式是主场：蓝灰色的暗底，暖白色的字（不是纯白），钢蓝主色，一点灯光般的琥珀色。浅色模式同样可用。
- **密度**：标准（1）。
- **标志细节**：专注模式。用户点某条待办的“专注”按钮后，页面其余部分盖上一层 `--dim` 遮罩并降低可交互性，只留这条待办和一个计时器在上层。再点一次或按 Esc 退出。遮罩出现用 `--dur` 渐变，减少动态时直接切换。
- **适合的骨架**：单栏或侧栏 + 主区。

### 庭院 courtyard

- **字体**：标题楷体（霞鹜文楷，带手写的温度），正文黑体。
- **配色**：天空般的浅蓝灰底，柿子橙主色，叶绿色辅助。另有六种“成员色” `--member-1` 到 `--member-6`。
- **密度**：略松（1.05），圆角较大。
- **标志细节**：每个家庭成员分配一种成员色。头像是名字的第一个字（圆形，成员色底，浅色模式白字）。日程、家务、待办上用同色小圆点或小头像标出是谁的。
- **适合的骨架**：单栏，或不均分网格（本周日程占主区）。

### 画室 studio

- **字体**：全黑体，标题字重 900。
- **配色**：近白底，克莱因蓝主色，明黄色只做荧光笔式的高亮背景。直角或极小圆角，没有阴影。
- **密度**：最松（1.2），大量留白。
- **标志细节**：首屏最上方，用 `--text-3xl`（手机上 `--text-2xl`）、克莱因蓝、字重 900，写出用户今天最重要的那一件事，可直接点击编辑。整页的“大胆”全部花在这一句上，其他模块保持安静。
- **适合的骨架**：单栏，或单栏 + 下方两列。

## 3. 字体加载

国内网络访问 Google Fonts 和部分国外 CDN 不稳定，而中文网络字体动辄几 MB。所以：

- **默认只用系统字体**：`themes.css` 里的字体栈已经按 macOS、Windows、Android、鸿蒙常见的中文字体排好，不加载任何网络字体也能正常显示。黑体在所有设备上都有；宋体和楷体在大多数电脑上也有系统版本。
- **用户想要更统一的效果时**，再按主题加载对应的网络字体，并告诉用户首次打开会稍慢：
  - 宋体（青瓷）：Noto Serif SC。Google Fonts 地址 `https://fonts.googleapis.com/css2?family=Noto+Serif+SC:wght@600;700&display=swap`；国内可换成镜像 `fonts.loli.net`（把域名 `fonts.googleapis.com` 替换掉，需实际测一下能否打开）。Google 会按字符切片加载，不会一次下全部。
  - 楷体（庭院）：霞鹜文楷屏幕阅读版，`https://cdn.jsdelivr.net/npm/lxgw-wenkai-screen-webfont/style.css`，字体名 `LXGW WenKai Screen`。jsDelivr 在国内偶有不稳，打不开时退回系统楷体即可。
- **网络字体只用在标题上**，正文始终用系统黑体，保证速度。
- 加载网络字体时加 `display=swap`，字体没下载完先用系统字体显示，不能出现空白。
- 不要引入主题没写到的其他字体。

## 4. 调整主题

用户想微调（“主色换成蓝的”“再紧凑一点”）时：

- 在页面里覆盖对应变量，例如 `html[data-theme="celadon"] { --primary: #2D5884; }`，同时给深色模式写对应值。
- 改颜色后检查对比度：正文对背景、按钮文字对按钮底色都要达到 4.5:1。
- 密度只改 `--density`（0.85 到 1.2 之间）。
- 不要因为微调就把标志细节去掉；用户明确说不要时才去掉。
